# Thiên Nghịch Châu · Huyễn Tâm · manual pack checklist

This checklist is a hand-review gate for the later Bead pack. It does not
dispatch ImageGen and does not grant ART, motion or runtime approval.

## Source and provenance

- [ ] Confirm the selected source id is `bead-a-{direction}-{core|damage|practice}-r1` and the prompt SHA equals the immutable preparation ledger.
- [ ] For each core source, verify the three exact input snapshots: own P1 Bead nearest8x (PRIMARY), Wang same-view (camera/anatomy/pixel support only), and own P1 full source (costume support only).
- [ ] For damage/practice, snapshot input 1 from the reviewed same-view own Bead core neutral and input 3 from that same own core raw; never use Sword, Banner, Chariot or a mirrored direction.
- [ ] Preserve the built-in ImageGen original path, original SHA, workspace raw SHA, transparent RGBA request and prompt/input hashes. Keep rejected/corrective sources as history.

## Body-only and direction

- [ ] Confirm every cell is an actual requested direction; no mirror, 90° rotation, or camera cheat. North is a true back; side views show the correct profile; front quarters preserve the own face and silver/charcoal identity.
- [ ] Body contains only the identity outfit, hair, hands, cuffs and dark boots. There is no orb, bead, temple, mountain, veil, qi, glow, target, floor, shadow or text.
- [ ] Own Huyễn Tâm charcoal/ivory/celadon outfit is PRIMARY. Wang pixels and face never enter the body. Keep the small sharp face, ponytail and human proportions.
- [ ] Preserve complete crown, ponytail, cuffs, hands and boot soles with transparent outer gutters and no alpha-edge clipping.

## Palm, cuff and root evidence

- [ ] Measure the dominant open palm/forearm and cuff in every real pose. Record `palm-up`, `seal`, `open`, `occluded` or `fragment` honestly with uncertainty; do not infer a palm from robe pixels.
- [ ] Register the hover anchor above the actual palm/forearm. It is not a held grip and never paints the orb into the body.
- [ ] Register actual boot/semantic roots per frame. Seated lotus and prone/death frames use measured support projections and a single baked lift; renderer never subtracts lift again.
- [ ] Head, torso and first recovery frames are reviewed before palm overlays. Run alternates real legs and never becomes a standing still pose.

## Clip and atlas packing

- [ ] Pack eight directions × eight actions (`idle`, `run`, `hit`, `death`, `meditate`, `gather`, `cast-single-target`, `cast-aoe`) with actual source key coverage; do not clone frames to meet six-key forecasts.
- [ ] Use one isotropic source factor from six own neutral crown-to-boot measurements. Normal frames use 112×112/(56,104); death/prone may use 192×128/(96,112) padding.
- [ ] Keep native RGBA exact, nearest sampling and gutter 2. Canonical frame and atlas bytes must match; source masks include disconnected hair/hand fragments.
- [ ] Cast key 4 starts fixture release at ST 600 ms / AOE 900 ms. Palm animation alone never creates a support/control fact.

## Separate Bead/FX contract

- [ ] The orb is a separate prop/FX layer hovering above the measured palm. It is never embedded, gripped or thrown like a sword.
- [ ] ST is support-only. AOE uses three sanctuary/support pulses and a distinct border-control effect, deduped by cast/pulse/target/spawnLife/effect kind.
- [ ] Inner-world temple/mountain/veil is a fixed-camera apparition. Do not rotate one camera plate as eight body views or turn it into a body/environment entity.
- [ ] Cancel before release produces no support/control fact; late facts retain their Core duration independent of body clip end. No damage, hit, XP or practice credit is implied.

## Completion gate

- [ ] Every selected source has `sourceViewed`, `socketReviewComplete`, `headTorsoFirstRecoveryReviewed` and `manualReviewPending: false` only after the above checks.
- [ ] Run scoped source/lineage/CPU/browser/Three QA after parent opens the generation gate. Keep `ownerApproved`, `motionApproved` and `runtimeIntegrated` false in this candidate package.
